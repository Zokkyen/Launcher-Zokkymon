## 🚀 Notes de version stable 0.4.1

Cette version prépare la compatibilité du launcher avec les mods qui demandent Fabric Loader 0.18.4.

- Nouveautés :
  - Passage du loader Fabric de 0.18.1 à 0.18.4 dans la configuration du launcher.

- Améliorations :
  - Alignement des valeurs Fabric entre la configuration locale, la configuration embarquée et les fichiers d'exemple.
  - Préparation de la branche main pour la release stable 0.4.1.

- Correctifs :
  - Réduction du risque de refus ou d'incompatibilité avec certains mods récents nécessitant explicitement Fabric 0.18.4.

## ✅ Recommandé

- Recommandé pour les joueurs qui doivent utiliser des mods ciblant Fabric 0.18.4.
- Vérifier après mise à jour que le pack démarre correctement et qu'aucun mod existant ne dépend d'un loader plus ancien.
